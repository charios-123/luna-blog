## Typescript 快速入门\n\n[Typescript 在线编译平台](https://www.typescriptlang.org/play)\n\n### ⼀、TypeScript 简介\n\n1. TypeScript 由微软开发，是基于 JavaScript 的⼀个扩展语⾔。\n2. TypeScript 包含了 JavaScript 的所有内容，即： TypeScript 是 JavaScript 的超集。\n3. TypeScript 增加了：静态类型检查、接口、泛型等很多现代开发特性，更适合大型项目的开发。\n4. TypeScript 需要编译为 JavaScript ，然后交给浏览器或其他 JavaScript 运行环境执行。\n\n### 二、为何需要 TypeScript\n\n**今非昔比的 JavaScript（了解）**\n\n- JavaScript 当年诞生时的定位是浏览器脚本语⾔，用于在网页嵌入简单的逻辑，且代码量很少。\n- 随着时间的推移，JavaScript 变得越来越流行，如今的 JavaScript 已经可以全栈编程了。\n- 现如今的 JavaScript 应用场景比当年丰富的多，代码量也比当年大很多，随便⼀个 JavaScript 项目的代码量，可以轻松的达到几万行，甚至十几万行！\n- 然而 JavaScript 当年“出生简陋”，没考虑到如今的应用场景和代码量，逐渐就出现了很多困扰。\n\n**JavaScript 中的困扰**\n\n😞 1. 不清楚的数据类型\n\n\n```\nlet welcome = 'hello'\nwelcome() // 此⾏报错：TypeError: welcome is not a function\n```\n\n😞 2. 有漏洞的逻辑\n\n\n```\nconst str = Date.now() % 2 ? '奇数' : '偶数'\n\nif (str !== '奇数') {\n  alert('hello')\n} else if (str === '偶数') {\n  alert('world')\n}\n```\n\n😞 3. 访问不存在的属性\n\n\n```\nconst obj = { width: 10, height: 15 }\nconst area = obj.width * obj.heigth\n```\n\n😞 4. 低级的拼写错误\n\n\n```\nconst message = 'hello,world'\nmessage.toUperCase()\n```\n\n**静态类型检查**\n\n- 在代码运行前进⾏检查，发现代码的错误或不合理之处，减小运行时出现异常的几率，此种检查叫『静态类型检查』，TypeScript 和核心就是『静态类型检查』，简⾔之就是把运行时的错误前置。\n- 同样的功能，TypeScript 的代码量要大于 JavaScript，但由于 TypeScript 的代码结构更加清晰，在后期代码的维护中 TypeScript 却胜于 JavaScript。\n\n### 三、编译 TypeScript\n\n浏览器不能直接运行 TypeScript 代码，需要编译为 JavaScript number ③ boolean ④ null ⑤ undefined ⑥ bigint ⑦ symbol ⑧ object\n\n> 备注：其中 object 包含： Array 、 Function 、 Date 、 Error 等…\n\n- null & undefined 默认是所有类型的子类型\n- strictNullChecks:true(strictNullChecks 、 boolean\n\n例如下面代码：\n\n\n```\nlet str1: string\nstr1 = 'hello'\nstr1 = new String('hello') // 报错\n\nlet str2: String\nstr2 = 'hello'\nstr2 = new String('hello')\n\nconsole.log(typeof （JavaScript引擎⾃动处理对象销毁，开发者⽆感知）\n  return lengthValue\n})()\n\nconsole.log(size) // 输出: 5\n```\n\n### 七、常⽤类型与语法\n\n#### 1. any\n\nany 的含义是：任意类型，⼀旦将变量类型限制为 any，那就意味着放弃了对该变量的类型检查。\n\n\n```\n// 明确的表示 a 的类型是 any —— 显式的 any\nlet a: any\n// 以下对 a 的赋值，均⽆警告\na = 100\na = '你好'\na = false\n\n// 没有明确的表示 b 的类型是 any，但TS主动推断出来 b 是 any —— 隐式的 any\nlet b\n// 以下对 b 的赋值，均⽆警告\nb = 100\nb = '你好'\nb = false\n\n/* 注意点：any 类型的变量，可以赋值给任意类型的变量 */\nlet c: any\nc = 9\n\nlet x: string\nx = c // ⽆警告\n```\n\n#### 2. unknown\n\nunknown 的含义是：未知类型，适用于：起初不确定数据的具体类型，要后期才能确定。unknown 任何类型的值都可以赋值给 unknown，unknown 只能赋值给 unknown、any\n\n1. unknown 可以理解为⼀个类型安全的 any 。\n\n\n```\n// 设置 a 的类型为 unknown\nlet a: unknown\n\n//以下对 a 的赋值，均符合规范\na = 100\na = false\na = '你好'\n\n// 设置 x 的数据类型为 string\nlet x: string\nx = a // 警告：不能将类型 “unknown” 分配给类型 “string”\n```\n\n1. unknown 会强制开发者在使⽤之前进⾏类型检查，从而提供更强的类型安全性。\n\n\n```\n// 设置 a 的类型为unknown\nlet a: unknown\na = 'hello'\n\n// 第⼀种⽅式：加类型判断\nif (typeof a === 'string') {\n  x = a\n  console.log(x)\n}\n\n// 第⼆种⽅式：加断⾔\nx = a as string\n\n// 第三种⽅式：加断⾔\nx = <string>a\n```\n\n1. 读取 any 类型数据的任何属性都不会报错，而 unknown 正好与之相反。\n\n\n```\nlet str1: string\nstr1 = 'hello'\nstr1.toUpperCase() // ⽆警告\n\nlet str2: any\nstr2 = 'hello'\nstr2.toUpperCase() // ⽆警告\n\nlet str3: unknown\nstr3 = 'hello'\nstr3.toUpperCase() // 警告：“str3” 的类型为 “未知”\n\n// 使⽤断⾔强制指定 str3 的类型为 string\n;(str3 as string).toUpperCase() // ⽆警告\n```\n\n#### 3. never\n\nnever 的含义是：任何值都不是，即：不能有值，例如 undefined、 null、 ‘’、 0 都不行！\n\n- never 永远不存在的值的类型\n- 抛出异常 根本没有返回值的函数表达式 或者箭头函数表达式返回值类型\n\n1. 几乎不用 never 去直接限制变量，因为没有意义，例如：\n\n\n```\n// 定 a 的类型为 never，那就意味着 a 以后不能存任何的数据了\nlet a: never\n\n// 以下对 a 的所有赋值都会有警告\na = 1\na = true\na = undefined\na = null\n```\n\n1. never ⼀般是 TypeScript 主动推断出来的，例如：\n\n\n```\n// 指定 a 的类型为 string\nlet a: string\n// 给 a 设置⼀个值\na = 'hello'\n\nif (typeof a === 'string') {\n  console.log(a.toUpperCase())\n} else {\n  console.log(a) // TypeScript会推断出此处的 a 是 never，因为没有任何⼀个值符合此处的逻辑\n}\n```\n\n1. never 也可用于限制函数的返回值\n\n\n```\n// 限制 throwError 函数不需要有任何返回值，任何值都不⾏，像 undefined、null 都不⾏\nfunction throwError(str: string): never {\n  throw new Error('程序异常退出:' + str)\n}\n```\n\n> never 类型的妙用\n> \n```\n> // ①\n> type Method = 'GET' | 'POST'\n> function request(url: string, method: Method) {\n> if (method === 'GET') {\n> // do something\n> } else if (method === 'POST') {\n> // do something\n> } else {\n> // 之后 Method 方法修改，这里会报错\n> const n: never = method\n> }\n> }\n> // ②\n> function m<T>(x: T extends number ? never : T) {}\n> ```\n\n#### 4. void\n\nvoid 的含义是空，即：函数不返回任何值，调⽤者也**不应依赖其返回值进行任何操作**！\n\n- void 没有任何类型，函数没有返回值，可以定义为 void\n\n1. void 通常用于函数返回值声明\n\n\n```\nfunction logMessage(msg: string): void {\n  console.log(msg)\n}\nlogMessage('你好')\n```\n\n> 注意：编码者没有编写 return 指定函数返回值，所以 logMessage 函数是没有显式返回值的，但会有⼀个隐式返回值 ，是 undefined，虽然函数返回类型为 void，但也是可以接受 undefined 的，简单记： undefined 是 void 可以接受的⼀种 “空”。\n\n1. 以下写法均符合规范\n\n\n```\n// ⽆警告\nfunction logMessage(msg: string): void {\n  console.log(msg)\n}\n\n// ⽆警告\nfunction logMessage(msg: string): void {\n  console.log(msg)\n  return\n}\n\n// ⽆警告\nfunction logMessage(msg: string): void {\n  console.log(msg)\n  return undefined\n}\n```\n\n1. 那限制函数返回值时，是不是 undefined 和 void 就没区别呢？—— 有区别。因为还有这句话：**返回值类型为 void 的函数，调用者不应依赖其返回值进⾏任何操作！**对比下面两段代码：\n\n\n```\n// ①\nfunction logMessage(msg: string): void {\n  console.log(msg)\n}\n\nlet result = logMessage('你好')\n\nif (result) {\n  // 此⾏报错：⽆法测试 "void" 类型的表达式的真实性\n  console.log('logMessage有返回值')\n}\n\n// ②\nfunction logMessage(msg: string): undefined {\n  console.log(msg)\n}\n\nlet result = logMessage('你好')\n\nif (result) {\n  // 此⾏⽆警告\n  console.log('logMessage有返回值')\n}\n```\n\n**理解 void 与 undefined**\n\n- void 是⼀个⼴泛的概念，⽤来表达“空”，而 undefined 则是这种“空”的具体实现。\n- 因此可以说 undefined 是 void 能接受的⼀种“空”的状态。\n- 也可以理解为： void 包含 undefined ，但 void 所表达的语义超越了 undefined， void 是⼀种意图上的约定，而不仅仅是特定值的限制。\n\n**总结：**\n\n如果⼀个函数返回类型为 void ，那么：\n\n1. 从语法上讲：函数是可以返回 undefined 的，至于显式返回，还是隐式返回，这无所谓！\n2. 从语义上讲：函数调用者不应关心函数返回的值，也不应依赖返回值进行任何操作！ 即使我们知道它返回了 undefined 。\n\n#### 5. object\n\n关于 object 与 Object ，直接说结论：实际开发中用的相对较少，因为范围太大了。\n\n##### object（小写）\n\nobject （小写）的含义是：所有非原始类型，可存储：对象、函数、数组等，由于限制的范围比较宽泛，在实际开发中使用的相对较少。\n\n\n```\nlet a: object // a 的值可以是任何【非原始类型】，包括：对象、函数、数组等\n\n// 以下代码，是将【非原始类型】赋给 a，所以均符合要求\na = {}\na = { name: '张三' }\na = [1, 3, 5, 7, 9]\na = function () {}\na = new String('123')\nclass Person {}\na = new Person()\n\n// 以下代码，是将【原始类型】赋给 a，有警告\na = 1 // 警告：不能将类型 “number” 分配给类型 “object”\na = true // 警告：不能将类型 “boolean” 分配给类型 “object”\na = '你好' // 警告：不能将类型 “string” 分配给类型 “object”\na = null // 警告：不能将类型 “null” 分配给类型 “object”\na = undefined // 警告：不能将类型 “undefined” 分配给类型 “object”\n```\n\n##### Object（大写）\n\n官⽅描述：所有可以调用 Object 方法的类型。简单记忆：除了 undefined 和 null 的任何值。由于限制的范围实在太大了！所以实际开发中使用频率极低。\n\n\n```\nlet b: Object // b 的值必须是 Object 的实例对象（除去 undefined 和 null 的任何值）\n\n// 以下代码，均⽆警告，因为给 a 赋的值，都是 Object 的实例对象\nb = {}\nb = { name: '张三' }\nb = [1, 3, 5, 7, 9]\nb = function () {}\nb = new String('123')\nclass Person {}\nb = new Person()\nb = 1 // 1 不是 Object 的实例对象，但其包装对象是 Object 的实例\nb = true // true 不是 Object 的实例对象，但其包装对象是 Object 的实例\nb = '你好' // “你好” 不是 Object 的实例对象，但其包装对象是 Object 的实例\n\n// 以下代码均有警告\nb = null // 警告：不能将类型 “null” 分配给类型 “Object”\nb = undefined // 警告：不能将类型 “undefined” 分配给类型 “Object”\n```\n\n##### 声明对象类型\n\n1. 实际开发中，限制⼀般对象，通常使用以下形式\n\n\n```\n// 限制 person1 对象必须有 name 属性，age 为可选属性\nlet person1: { name: string; age?: number }\n\n// 含义同上，也能⽤换⾏做分隔\nlet person2: {\n  name: string\n  age?: number\n}\n\n// 如下赋值均可以\nperson1 = { name: '李四', age: 18 }\nperson2 = { name: '张三' }\n\n// 如下赋值不合法，因为 person2 的类型限制中，没有对 gender 属性的说明\nperson2 = { name: '王五', gender: '男' }\n```\n\n1. 索引签名： 允许定义对象可以具有任意数量的属性，这些属性的键和类型是可变的， 常用于：描述类型不确定的属性，（具有动态属性的对象）。\n\n\n```\n// 限制 person 对象必须有 name 属性，可选 age 属性但值必须是数字，同时可以有任意数量、任意类型的其他属性\nlet person: {\n  name: string\n  age?: number\n  [key: string]: any // 索引签名，完全可以不⽤ key 这个单词，换成其他的也可以\n}\n\n// 赋值合法\nperson = {\n  name: '张三',\n  age: 18,\n  gender: '男'\n}\n```\n\n##### 声明函数类型\n\n\n```\nlet count: (a: number, b: number) => number\n\ncount = function (x, y) {\n  return x + y\n}\n```\n\n> **备注**：\n> - TypeScript 中的 => 在函数类型声明时表示函数类型，描述其参数类型和返回类型。\n> - JavaScript 中的 => 是一种定义函数的语法，是具体的函数实现。\n> - 函数类型声明还可以使用：接口、自定义类型等方式，下文中会详细讲解。\n\n##### 声明数组类型\n\n\n```\nlet arr1: string[]\nlet arr2: Array<string>\n\narr1 = ['a', 'b', 'c']\narr2 = ['hello', 'world']\n```\n\n> 备注：上述代码中的 Array 属于泛型，下文会详细讲解。\n\n#### 6. tuple\n\n元组 (Tuple) 是⼀种特殊的数组类型，可以存储固定数量的元素，并且每个元素的类型是已知的且可以不同。元组用于精确描述一组值的类型，`?`表示可选元素。\n\n\n```\n// 第⼀个元素必须是 string 类型，第⼆个元素必须是 number 类型。\nlet arr1: [string, number]\n// 抽象类\n\n概述：抽象类是⼀种无法被实例化的类，专门用来定义类的结构和行为，类中可以写抽象方法，也可以写具体实现。抽象类主要用来为其派生类提供⼀个基础结构，要求其派生类必须实现其中的抽象方法。\n\n简记：抽象类不能实例化，其意义是可以被继承，抽象类⾥可以有普通方法、也可以有抽象方法。\n\n通过以下场景，理解抽象类：\n\n> 我们定义⼀个抽象类 Package ，表示所有包裹的基本结构，任何包裹都有重量属性 weight ，包裹都需要计算运费。但不同类型的包裹（如：标准速度、特快专递）都有不同的运费计算方式，因此用于计算运费的 calculate 方法是⼀个抽象方法，必须由具体的子类来实现。\n\n\n```\n// Package 类\nabstract class Package {\n  constructor(public weight: number) {}\n  // 抽象⽅法：⽤来计算运费，不同类型包裹有不同的计算⽅式\n  abstract calculate(): number\n  // 通⽤⽅法：打印包裹详情\n  printPackage() {\n    console.log(`包裹重量为: ${this.weight}kg，运费为: ${this.calculate()}元`)\n  }\n}\n```\n\nStandardPackage 类继承了 Package ，实现了 calculate 方法：\n\n\n```\n// StandardPackage 类 （标快包裹）\nclass StandardPackage extends Package {\n  constructor(\n    weight: number,\n    public unitPrice: number // 每公⽄的固定费率\n  ) {\n    super(weight)\n  }\n  // 实现抽象⽅法：计算运费\n  calculate(): number {\n    return this.weight * this.unitPrice\n  }\n}\n\n// 创建标准包裹实例\nconst s1 = new StandardPackage(10, 5)\ns1.printPackage()\n```\n\nExpressPackage 类继承了 Package ，实现了 calculate 方法：\n\n\n```\n// ExpressPackage 类（特快包裹）\nclass ExpressPackage extends Package {\n```\n\n  constructor(\n    weight: number,\n\n```\n    private unitPrice: number, // 每公⽄的固定费率（快速包裹更⾼）\n    private additional: number // 超出 10kg 以后的附加费\n  ) {\n    super(weight)\n  }\n  // 实现抽象⽅法：计算运费\n  calculate(): number {\n    if (this.weight > 10) {\n      // 超出 10kg 的部分，每公⽄多收 additional 对应的价格\n      return 10 * this.unitPrice + (this.weight - 10) * this.additional\n    } else {\n      return this.weight * this.unitPrice\n    }\n  }\n}\n```\n\n\n\n```\n// 创建特快包裹实例\nconst e1 = new ExpressPackage(13, 8, 2)\n```\n\ne1.printPackage()\n\n**总结**：\n\n何时使用抽象类？\n\n1. 定义通用接口 ：为⼀组相关的类定义通用的行为（方法或属性）时。\n2. 提供基础实现 ：在抽象类中提供某些方法或为其提供基础实现，这样派生类就可以继承这些实现。\n3. 确保关键实现 ：强制派生类实现⼀些关键行为。\n4. 共享代码和逻辑：当多个类需要共享部分代码时，抽象类可以避免代码重复。\n\n#### 13. interface（接口）\n\ninterface 是⼀种定义结构的⽅式，主要作用是为：类、对象、函数等规定⼀种契约，这样可以确保代码的⼀致性和类型安全，但要注意
